# Аудит соответствия паспорту СППР — версия 0.2.0

Дата: 12.11.2026. Сравнены шаблон «Паспорт СППР.md» из Downloads, фактическая реализация и результаты запусков. Шаблон сохранен без изменения; заполненный паспорт находится в корне проекта. Восемь практик шаблона не совпадают с нумерацией восьми этапов исходного плана, поэтому соответствие проверено по содержанию и инструментам.

| Практика | До аудита | Что выполнено / доказательство |
|---|---|---|
| 1. Постановка | Реализована | Анкета, критерии, жесткие ограничения, происхождение/режим данных; формальная постановка в паспорте |
| 2. AHP, Python/Excel | Были swing-веса, AHP и Excel отсутствовали | ahp.py, проверка CR и связи весов с запросом, ввод шести сравнений в UI, AHP.xlsx с формулами, ahp.json; учебные отношения альтернатив отделены от рабочих абсолютных шкал |
| 3. SciPy/NetworkX | Были сценарии/риск/закрытия, не было дерева стратегий | decision_analysis.py: ориентированное дерево, ожидаемые полезности, brentq для порога, чувствительность; decision_tree.png и summary.json |

| 6. Прогноз и Superset/DataLens | Прогноз был, BI ограничивался Streamlit | Настоящий Apache Superset 4.1.4 в отдельной среде; 4 датасета/графика/дашборд; четыре REST-запроса HTTP 200 (3/6/365/40 строк), экспорт HTTP 200 |

| 8. Интеграция | Рабочий MVP и инструкции | Паспорт, документация новых модулей, сценарий использования/приемки и обновленный комплект передачи |

## Измеренные результаты

- AHP: w=(.455407964,.262832869,.140879584,.140879584), λ=4.010362902, CI=.003454301, CR=.003838112. Изменение сравнения 2→5 меняет первый вес .455408→.548106; восстановление возвращает исходные значения. В сохраненной Excel-книге проверены формулы и cached values. Нативный Excel не запускался.
- PuLP: на 20 задачах 3–5 POI статус OPTIMAL и совпадение с полным перебором до 1e-6; на полном поиске FEASIBLE, основной Ярославль U=.780035, 27 940 ₽, проверочная успешность .934. Глобальная оптимальность полного поиска не заявлена.
- CP-SAT/AHP: 24 сочетания услуг, 13 кандидатов, три выбранных плана за ~52.7 с; Ярославль U=.836992, 24 490 ₽, C90=28 010.24 ₽, 1000/1000 успешных сценариев. Санкт-Петербург .883 не достигает порога .9 и явно предупреждается.
- Дерево: порог резерва для основного Ярославля ~.9677% при L=−.2, k=.01. Частота закрытий не оценивалась.
- Protégé: OWL загружен; headless OWL API 4.5.29/HermiT 1.4.3.456 из официального дистрибутива 5.6.9 подтвердили согласованность и вывод. На Java 21 наблюдалось предупреждение меню AquaLookAndFeel, отдельно отмеченное в инструкции.
- Superset: Python 3.11, отдельные фиксированные зависимости, SQLite-витрины, настоящие объекты метаданных и запросы. Проверка API не выдается за пользовательскую визуальную приемку.

Машинные протоколы: [ahp](passport/ahp.json), [проверка книги](passport/workbook_check.json), [PuLP](passport/pulp_recommendation.json), [CP-SAT](passport/cp_sat_recommendation.json), [MILP](passport/milp.json), [БЗ](passport/knowledge.json), [OWL](passport/protege_check.json), [BI](passport/superset_queries.json). Сводная проверка основного окружения и тестов: [verification.json](passport/verification.json).

## Актуальные оговорки

Ранее сохраненные STAGES_1_4.md, STAGES_5_8.md, full_demo.* и эксперименты документируют предыдущую реализацию/swing-запрос. Новые AHP-результаты и обязательные инструменты описаны этим аудитом и паспортом; они не приписываются старым экспериментам. Новое пользовательское исследование не проводилось по договоренности с владельцем. Репозиторий/видео не создавались: вместо внешних ссылок в паспорте даны инструкции по публикации и записи. Реальные котировки, новое обучение на будущих данных и публичное развертывание не являются выполненными этапами.

Первичная независимая передача 0.1.0 проверялась на Python 3.11/Apple Silicon. После изменений подготовлен отдельный архив 0.2.0, его фактическая контрольная сумма и результаты проверки распакованной копии находятся в dist/handoff_verification.json, вне архива во избежание циклического хеширования. Superset требует отдельной установки по docs/PASSPORT_TOOLS.md; его пароль и локальные базы не передаются.
