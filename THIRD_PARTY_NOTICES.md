# Источники и обозначения данных

Этот файл сопровождает снимки данных при передаче проекта. Он не заменяет лицензии соответствующих источников или Python-зависимостей.

- **Open-Meteo / ERA5.** История погоды и производные обученные модели: [Open-Meteo](https://open-meteo.com/), [документация](https://open-meteo.com/en/docs/historical-weather-api), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Weather data by Open-Meteo. URL запроса и модель указаны рядом с каждым CSV. Это реанализ, а не непосредственные наблюдения городской метеостанции.
- **OpenStreetMap.** Map data © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Сохранены исходные выгрузки, координаты и производные каталоги. Указание источника и условий сохраняется при передаче.
- **FOSSGIS / OSRM.** Пешеходные матрицы получены с публичного сервера: [условия](https://routing.openstreetmap.de/about.html), [исправить карту](https://www.openstreetmap.org/fixthemap). Routing by FOSSGIS OSRM, на данных OSM. Для воспроизведения достаточно сохраненных ответов; повторная массовая загрузка не требуется.
- **Демонстрационный API.** Цены, расписания, доступность, предложения и дополнительные связи матриц в `data/api/demo_catalog.json` смоделированы внутри проекта. `travel-dss.example` обозначает условный источник; это не действующий API и не предложения бронирования. Исходные географические ссылки OSM сохранены в JSON.

Python-зависимости устанавливаются из PyPI по `requirements.lock`; их лицензии и metadata включены в соответствующие установленные пакеты. Окружение `.venv` и кеши в архив передачи не включаются.
